## ⚡ آموزش گام‌به‌گام نحوه استفاده و اتصال

### ۱. آموزش نحوه استفاده در اندروید (v2rayNG):
1. نرم‌افزار [v2rayNG را دانلود و نصب کنید](https://github.com/2dust/v2rayNG/releases).
2. وارد [ربات روزنه نت (@RoozanehNetBot)](https://t.me/RoozanehNetBot) شوید و کانفیگ تست یا اشتراک خریداری‌شده خود را کپی کنید.
3. برنامه v2rayNG را باز کنید، روی علامت **+** در بالای صفحه بزنید.
4. گزینه **Import config from Clipboard** را لمس نمایید.
5. دکمه اتصال (دایره پایین صفحه) را لمس کنید تا متصل شوید.
* *نکته تست:* برای تست اتصال، روی کانفیگ بزنید تا پینگ سبز رنگ نمایش داده شود.

### ۲. آموزش نحوه استفاده در آیفون (iOS):
1. نرم‌افزار [V2Box را از اپ‌استور دانلود کنید](https://apps.apple.com/app/v2box-v2ray-client/id6446814690).
2. لینک اشتراک سابسکریپشن خود را از [ربات تلگرام](https://t.me/RoozanehNetBot) کپی کنید.
3. در برنامه V2Box به بخش **Configs** بروید، دکمه **+** را بزنید و گزینه **Import V2ray URL from Clipboard** را انتخاب نمایید.
4. در تب Home، دکمه اتصال را بکشید تا اینترنت آزاد فعال شود.
